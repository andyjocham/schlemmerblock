# Schlemmerblock auf dem iPhone

## Empfohlen: als Webseite auf dem iPhone

Wenn `.html` auf dem iPhone mit AnyDesk verknuepft ist, ist der lokale Dateiweg nicht zuverlaessig. Am besten die Karte als kleine Webseite veroeffentlichen, z. B. per GitHub Pages.

Die vorbereitete Datei dafuer liegt hier:

`docs/index.html`

Kurzanleitung:

1. `docs/index.html` auf GitHub Pages veroeffentlichen.
2. Die GitHub-Pages-Adresse auf dem iPhone in Safari oeffnen.
3. Teilen-Symbol antippen.
4. `Zum Home-Bildschirm` waehlen.

Die schicke zoombare Karte braucht unterwegs Internet, weil die Kartenkacheln nachgeladen werden. Suche, Orte, Kategorien, Filter und die Besucht-Haken bleiben lokal auf dem iPhone gespeichert.

Eine genaue GitHub-Pages-Anleitung steht in `GITHUB_PAGES.md`.

## Im WLAN vom Mac

1. Mac und iPhone muessen im gleichen WLAN sein.
2. Auf dem Mac `start-karte-iphone.command` doppelklicken.
3. Auf dem iPhone in Safari die angezeigte Adresse oeffnen.
4. In Safari auf das Teilen-Symbol tippen.
5. `Zum Home-Bildschirm` waehlen.

Danach kann die Karte wie eine kleine App vom Home-Bildschirm gestartet werden.

Wichtig: Das Terminal-Fenster auf dem Mac muss offen bleiben, solange die Karte auf dem iPhone genutzt wird.
